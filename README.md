# Vesper

A pure, statically typed functional programming language implemented in OCaml with Hindley-Milner type inference, a bytecode virtual machine, and a built-in developer toolchain.

## Tech Stack

- **OCaml** (>= 5.0.0)
- **Dune** (>= 3.14)
- **Menhir & ocamllex**
- **Alcotest**
- **OCamlFormat**
